# دیدبان امنیت — نسخهٔ ۲۰ آفلاین

سامانه جامع ممیزی مدیریت امنیت اطلاعات؛ بر پایه نسخهٔ ۱۹ ارسالی کاربر، با تغییرات محدود در گزارش ممیزی و ورود اطلاعات BCMS.

- [دانلود ZIP نسخهٔ ۲۰](Didban_Amniat_Offline_v20.zip?raw=true)
- [فایل اصلی HTML](Didban_Amniat_Offline.html)
- [فایل خام برای ارسال به دیگران](Didban_Amniat_Offline_Fresh.html)
- [جزئیات نسخهٔ ۲۰ و سازگاری داده‌ها](docs/V20-CHANGES.md)

ZIP را استخراج و **START_HERE.html** یا فایل اصلی HTML را در مرورگر باز کنید. نصب، اینترنت و سرور لازم نیست. برای انتقال بین پوشه‌ها، مرورگرها یا رایانه‌ها ابتدا JSON پروژه را از پشتیبانی بگیرید.

در فرم گزارش، خروجی جدید **دریافت گزارش HTML** اضافه شده است. گزارش مستقل با منو، نمودار، جستجو و فیلتر، فقط الزامات و Annex A را نمایش می‌دهد. همین محدوده در Word، Excel و چاپ/PDF رعایت شده است. شرح یافته فقط فیلدهای پرشده را می‌آورد و ستون یافتهٔ Word رنگ‌های نرم‌افزار را دارد. گزارش‌های مستقل اقدامات اصلاحی در بخش خودشان باقی‌اند.

فرم BCMS نه‌تبی است؛ ماتریس ارتباطات اضطراری و وظایف، منابع طرح و مستندات قابل ثبت‌اند. نمای گرافیکی در تب آخر، مقادیر شاخص‌ها و موارد نیازمند بررسی را نشان می‌دهد. فیلدهای قبلی، واحدها، نسخهٔ داده و کلیدهای ذخیره‌سازی حفظ شده‌اند؛ اطلاعات جدید فقط ویژگی‌های اختیاری همان طرح‌اند.

راهنمای کامل در `docs/USER-GUIDE.md` و یادداشت نسخه در `docs/V20-CHANGES.md` قرار دارد. پوشه Source برای توسعه است؛ برای اجرا فقط HTML لازم است.
