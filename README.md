# دیدبان امنیت ۸ — آفلاین و مینیمال

[دانلود ZIP نسخهٔ ۸](Didban_Amniat_Offline_v8.zip?raw=true)

ZIP را استخراج کنید و `START_HERE.html` یا `Didban_Amniat_Offline.html` را در Chrome یا Edge باز کنید. برنامه، فونت‌ها، نمودارها و خروجی‌های Excel و Word داخل بسته‌اند؛ اینترنت، نصب، سرور و CDN لازم نیست.

RTP فقط سه زیرمنو دارد: داشبورد، دفتر پروژه‌ها، بودجه و هزینه‌ها. ثبت پروژه‌ها و فعالیت‌ها مستقیماً در جدول با ذخیرهٔ خودکار، چسباندن چندسلولی و ورود و خروج Excel انجام می‌شود. پیشرفت ۱۰۰٪ با اثربخشی و اختتام موفق RTP متفاوت است.

BCMS فقط سه زیرمنو دارد: داشبورد، ارزیابی BIA و راهنما. هر ارزیابی در پنج کارت جمع‌شونده ثبت می‌شود. اهداف بازیابی، شکاف‌ها، نتیجهٔ تمرین و آمادگی از داده‌ها محاسبه می‌شوند. دادهٔ ناقص هرگز «آماده» محسوب نمی‌شود.

پوستهٔ روشن آبی و فیروزه‌ای، تاریخ‌ها و تقویم شمسی، عنوان‌های دوزبانهٔ داشبورد و رادار ۱۲۳ بند و کنترل به‌روز شده‌اند. اطلاعات تکمیلی ممیزی شامل نام ممیز، اقدام اصلاحی و انطباق ممیزی قبلی است. سایر امکانات نسخهٔ ۶ حفظ شده‌اند.

اطلاعات در مرورگر ذخیره می‌شود و فایل HTML با ورود اطلاعات تغییر نمی‌کند. از بخش پشتیبانی سایت مرتب JSON بگیرید. هر پروژهٔ ممیزی دفترهای مستقل دارد؛ اطلاعات RTP و BCMS وارد داشبورد اصلی نمی‌شود. ساختارهای سنگین نسخهٔ ۷ و الزام مهاجرت داده‌های آنها حذف شده‌اند. پشتیبان ماژول‌های نسخهٔ ۷ با ساختار مینیمال سازگار نیست.

راهنمای کاربر و فرمول‌ها در پوشهٔ `docs` قرار دارند. نسخهٔ Fresh فضای ذخیره‌سازی مستقلی دارد.

برای توسعه (برای اجرای برنامه لازم نیست):

```sh
npm ci
npm run build
npm test
```

آزمون مرورگر با Python و Playwright: `python tests/browser.py --url http://127.0.0.1:8765/Didban_Amniat_Offline.html`. بستهٔ دانلودی شامل منبع ساخت است؛ وابستگی‌های npm فقط هنگام توسعه استفاده می‌شوند.
