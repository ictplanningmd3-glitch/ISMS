# دیدبان امنیت — نسخه ۷ آفلاین

[دریافت ZIP کامل نسخه ۷](Didban_Amniat_Offline_v7.zip?raw=true) · [فایل HTML مستقل](Didban_Amniat_Offline.html?raw=true)

ادامه نسخه ۶ (`cdf79ea`) با حفظ قابلیت‌ها و داده‌های ممیزی موجود و دو ماژول مستقل **Risk Treatment Plan** و **BCMS / BIA & BCP**. برنامه با بازکردن HTML در مرورگر اجرا می‌شود؛ برای استفاده اینترنت، نصب، سرور یا پایگاه داده خارجی لازم نیست.

## اجرا

ZIP را استخراج و `Didban_Amniat_Offline.html` را باز کنید. `Didban_Amniat_Offline_Fresh.html` برای شروع مستقل است. نام‌های قدیمی `Didban_ISMS_Offline` نیز برای سازگاری حفظ شده‌اند.

برای انتقال مطمئن اطلاعات، از نسخه قبلی JSON پروژه را بگیرید و در پشتیبانی نسخه جدید بارگذاری کنید. در همان مرورگر و فضای قبلی، کلیدها و پروژه‌های نسخه ۶ حفظ می‌شوند. جابه‌جایی فایل ممکن است فضای ذخیره‌سازی مرورگر را جدا کند؛ JSON راه مطمئن انتقال است.

## تغییرات

* منوها با ترتیب درخواستی، آیکون SVG و نام‌های «داشبورد مدیریتی» و «اقدامات اصلاحی».
* RTP مستقل: ریسک، برنامه مواجهه، پورتفوی، پروژه، WBS، گانت، نقاط عطف، هزینه، Baseline، آزمون اثربخشی، پذیرش ریسک، هشدار، گزارش و تاریخچه.
* رادارهای مستقل عملکرد پروژه و اثربخشی مواجهه؛ رادار ترکیبی هشت‌بعدی، فیلتر، مقایسه واحدها، هدف، مبنای تاریخی، Snapshot نسخه‌دار و PNG.
* BCMS مستقل: محصول/خدمت، فعالیت، منابع، وابستگی، BIA چهارده‌مرحله‌ای، BCP، تمرین و آزمون، اقدام اصلاحی، بازنگری، گزارش و مرکز دانش.
* داشبورد اختصاصی هر ماژول؛ داده‌های RTP و BCMS وارد داشبورد اصلی ممیزی نمی‌شود.
* رادار بزرگ Annex A با طیف قرمز تا سبز، دسته‌های دوطرفه، انتخاب هم‌زمان حوزه، توقف پویانمایی و رعایت کاهش حرکت.
* توکن‌های Indigo/Slate و Teal؛ حالت روشن، تاریک و سیستم؛ وضعیت‌های معنایی و نمودارهای سازگار با پوسته؛ فونت‌های Vazirmatn و Inter تعبیه‌شده.
* JSON کامل پروژه شامل داده‌های قبلی و هر دو ماژول، پشتیبان ماژولی، Excel/PDF، پیوست آفلاین، نسخه و تاریخچه.

## داده و هویت

هر پروژه، دفتر مستقل ممیزی، اقدامات اصلاحی، ریسک قدیمی، RTP، BCMS و مشخصات گزارش دارد. داده در مرورگر ذخیره می‌شود؛ ثبت داده خود HTML را تغییر نمی‌دهد. از «پشتیبانی سایت ← دریافت JSON پروژه فعال» مرتب پشتیبان بگیرید. import پیش‌فرض پروژه جدید می‌سازد. پاک‌کردن داده فقط پروژه فعال را با تأیید عنوان پاک می‌کند.

تصویب‌های ماژول‌های جدید نیازمند حساب محلی مجاز است. حساب اول مدیر سیستم است؛ پذیرش ریسک فقط توسط حساب نقش مالک همان ریسک انجام می‌شود. گذرواژه با PBKDF2 و salt تصادفی نگهداری می‌شود. این بسته آفلاین احراز هویت امن سرور، امنیت چندکاربره یا رمزگذاری داده عملیاتی ندارد. بخش‌های قبلی گردش کار خود را حفظ می‌کنند.

## ساخت و آزمون توسعه

برای استفاده از نرم‌افزار این دستورات لازم نیستند. برای تغییر منبع، Node.js، Python 3 و ابزار توسعه esbuild لازم است:

```sh
npm install
npm run build
npm test
```

ساخت با esbuild موجود در مسیر دیگر:

```sh
python build.py --esbuild /absolute/path/to/esbuild
```

آزمون مرورگر با Python Playwright، Chromium و سرور استاتیک محلی:

```sh
python -m http.server 8765 --bind 127.0.0.1
python tests/browser.py http://127.0.0.1:8765/
```
