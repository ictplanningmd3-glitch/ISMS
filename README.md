# دیدبان امنیت

سامانه جامع ممیزی مدیریت امنیت اطلاعات — نسخه آفلاین ۵

فایل اصلی: [Didban_Amniat_Offline.html](Didban_Amniat_Offline.html)

نسخه فشرده: [Didban_Amniat_Offline.zip](Didban_Amniat_Offline.zip)

فایل HTML را دانلود و در مرورگر باز کنید. نصب، اتصال به اینترنت یا سرویس خارجی لازم نیست. فایل‌های دارای نام قبلی نیز برای حفظ لینک‌های دانلود قبلی، همان نسخه جدید را ارائه می‌کنند.

## تغییرات این نسخه

- فونت B Yekan معمولی و تعبیه‌شده در فایل، بدون بولد مصنوعی.
- نشان اختصاصی، عنوان «دیدبان امنیت» و منوی جدید؛ مدیریت ریسک پس از روش ارزیابی و پشتیبانی سایت پس از آن.
- دسترسی سریع به بخش‌های نمای کلی و جستجو در محتوا، راهنمای بندها، شواهد، مشاهدات، اقدامات بهبود، دارایی‌ها و ریسک‌ها.
- آیکون‌های مستقل حالت تاریک، چاپ، PDF، ثبت ارزیابی و گزارش Word و Excel در نوار بالایی.
- گزارش واقعی `.docx` و `.xlsx` شامل تمام ۳۰ الزام و ۹۳ کنترل؛ وضعیت انطباق، شواهد ممیزی، مشاهدات، مسئول، اقدامات پیشنهادی و مهلت برای هر مورد درج می‌شود. داده‌های ماژول مستقل ریسک در ضمیمه جداگانه گزارش می‌آیند.
- «اقدامات پیشنهادی» به صورت کادر چندخطی بزرگ‌تر؛ ویرایش و ذخیره وضعیت انطباق در همه کنترل‌ها و الزامات بررسی شده است.
- پشتیبان جامع JSON و بارگذاری آن در بخش پشتیبانی سایت؛ سازگار با نسخه‌های قدیمی ممیزی و JSON مستقل ریسک.

## اطلاعات و گزارش‌ها

اطلاعات در حافظه همان مرورگر ذخیره می‌شود. پیش از جابه‌جایی فایل یا تعویض نسخه، از ممیزی و ریسک نسخه JSON بگیرید. برای انتقال، آن را از بخش پشتیبانی سایت بارگذاری کنید. داده‌های نمونه به عنوان ممیزی واقعی ذخیره نمی‌شوند؛ بازکردن فرم از نمای نمونه، فرم داده واقعی را باز می‌کند.

برای تهیه PDF، آیکون PDF را بزنید و در پنجره چاپ مرورگر، مقصد «Save as PDF» را انتخاب کنید. گزارش کامل چاپی همان محتوای ممیزی و ضمائم را دارد. فایل‌های Word و Excel قابل ویرایش هستند.

دانلود HTML از داخل برنامه، نسخه‌ای همراه داده‌های ذخیره‌شده مرورگر می‌سازد؛ آن نسخه محرمانه است. در مرورگر مقصد، داده همراه فقط در حافظه خالی بازیابی می‌شود. برای جایگزینی داده موجود از JSON استفاده کنید. فایل منتشرشده در این مخزن فاقد اطلاعات شخصی یا داده‌های آزمایشی است.

## بررسی نسخه

ذخیره و بازخوانی انطباق، شواهد و اقدامات پیشنهادی برای هر ۱۲۳ مورد؛ ویرایش دارایی، ریسک، زمینه و پروژه؛ سازگاری پشتیبان‌های قدیمی و بازیابی نسخه HTML در حافظه خالی؛ بررسی گزارش‌ها با `python-docx` و `openpyxl`؛ تولید PDF کامل؛ نمایش موبایل و عملکرد بدون درخواست خارجی، آزمایش شده‌اند.
