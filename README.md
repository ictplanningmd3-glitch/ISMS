# دیدبان امنیت ۱۴ — کاملاً آفلاین

[دانلود ZIP نسخهٔ ۱۴](Didban_Amniat_Offline_v14.zip?raw=true)

ZIP را استخراج و `Didban_Amniat_Offline.html` یا `START_HERE.html` را با Chrome یا Edge باز کنید. برنامه، فونت‌ها، نمودارها و خروجی‌های Word و Excel داخل بسته‌اند؛ اینترنت، نصب، سرور و CDN لازم نیست.

نمودار «توزیع نتایج ممیزی» در داشبورد مدیریتی همهٔ نتایج ثبت‌شده را به ترتیب رادار نشان می‌دهد: نقطه قوت، انطباق، توصیه برای بهبود، مشاهده، عدم انطباق جزیی و عدم انطباق کلی. هر ردیف از نتایج معتبر همان حوزه به ۱۰۰٪ نرمال می‌شود؛ موارد ارزیابی‌نشده در مخرج قرار ندارند.

الزامات در هشت حوزه قرار دارند: شناخت سازمان، دامنه و ذینفعان؛ رهبری و حاکمیت؛ مدیریت ریسک؛ اهداف و طرح‌ریزی تغییرات؛ منابع، شایستگی و آگاهی؛ ارتباطات و اطلاعات مدون؛ کنترل عملیاتی؛ ارزیابی عملکرد و بهبود. نگاشت ۳۰ بند همچنان کامل و یکتا است و ده حوزهٔ Annex A شامل ۹۳ کنترل حفظ شده‌اند. فایل‌های [Excel کنترل‌ها](assets/Annex_A_Domains.xlsx)، [Excel الزامات](assets/Clause_Domains.xlsx) و [توضیحات نگاشت](docs/ANNEX-A-MAPPING.md) همراه بسته‌اند.

زیرمنوی «داشبورد اقدامات اصلاحی» فقط یافته‌های مشاهده، توصیه برای بهبود و عدم انطباق جزیی/کلی را پیگیری می‌کند. جدول چهار ستون دارد: الزام/کنترل، وضعیت ممیزی، پروژه‌های بهبود تعریف‌شده و وضعیت اقدام. تمام پروژه‌های مرتبط، حتی تکمیل‌شده‌ها، نمایش داده می‌شوند. نبود پروژه یعنی برنامه‌ریزی‌نشده؛ وجود پروژهٔ ناتمام یعنی در حال اقدام؛ تکمیل همهٔ پروژه‌های مرتبط یعنی اقدام‌شده. وضعیت اقدام خودکار است و نتیجهٔ ممیزی را عوض نمی‌کند. ایجاد پروژه در بخش «پروژه‌های بهبود» انجام می‌شود.

چهار شاخص داشبورد، تعداد یافته‌های نیازمند اقدام، کل پروژه‌ها، پروژه‌های تکمیل‌شده و تکمیل‌نشده را نشان می‌دهند. دو نمودار انباشتهٔ مستقل برای کنترل‌ها و الزامات، مهلت پروژه‌ها و تعداد پروژه‌های تکمیل‌شدهٔ مرتبط با هر مجموعه نمایش داده می‌شوند.

کارت‌های A/B/C، بودجهٔ پروژه‌ها، ساختار RTP و BCMS، تقویم شمسی، پشتیبان و گزارش‌ها حفظ شده‌اند. داده‌ها در مرورگر ذخیره می‌شوند؛ خود HTML با ورود اطلاعات تغییر نمی‌کند. از بخش پشتیبانی مرتب پشتیبان JSON بگیرید.

برای استفادهٔ روزانه اجرای کدهای Source لازم نیست. توسعه:

```sh
npm ci
npm run build
npm test
```

آزمون‌های مرورگر با Python، Playwright و Chromium در پوشهٔ `tests` قرار دارند.
