# دیدبان امنیت ۱۳ — کاملاً آفلاین

[دانلود ZIP نسخهٔ ۱۳](Didban_Amniat_Offline_v13.zip?raw=true)

ZIP را استخراج و `Didban_Amniat_Offline.html` یا `START_HERE.html` را با Chrome یا Edge باز کنید. برنامه، فونت‌ها، نمودارها و خروجی‌های Word و Excel داخل بسته‌اند؛ اینترنت، نصب، سرور و CDN لازم نیست.

داشبورد مدیریتی در نسخهٔ ۱۳ خلوت‌تر است: آخرین ارزیابی‌ها، عملکرد قدیمی حوزه‌های Annex A و خلاصهٔ پروژه‌های بهبود حذف شده‌اند. توزیع عدم‌انطباق‌های جزئی و کلی در ده حوزهٔ کنترل و ده حوزهٔ الزامات با نمودار میله‌ای انباشتهٔ ۱۰۰٪ نمایش داده می‌شود. شمارش و درصد از داده‌های واقعی ثبت‌شده‌اند؛ نبود ارزیابی به‌معنی انطباق نیست. بوک‌مارک‌های صفحه به بخش‌های موجود متصل‌اند.

ترتیب وضعیت‌های انطباق از مرکز رادار به بیرون و در نمودارها: نقطه قوت (Good Point)، انطباق، توصیه برای بهبود، مشاهده، عدم انطباق جزئی و عدم انطباق کلی. ثبت‌نشده بیرون رادار خاکستری است. گزینهٔ Good Point در منوی انتخاب ساده است؛ رنگ بنفش در نمودارها و نشان‌های نتیجه باقی می‌ماند.

تقسیم‌بندی مشترک ده حوزهٔ Annex A از یک منبع (`src/taxonomy-v13.json`) به رادار، فیلترها، پروژه‌های بهبود و گزارش‌ها اعمال می‌شود. نام‌ها و نگاشت‌ها دقیقاً از دو جدول متنی ارائه‌شدهٔ کاربر گرفته شده‌اند: ۹۳ کنترل Annex A و ۳۰ الزام اصلی، هر یک دقیقاً در یکی از ده حوزهٔ خود قرار دارند. فایل‌های [Excel کنترل‌ها](assets/Annex_A_Domains.xlsx)، [CSV کنترل‌ها](assets/Annex_A_Domains.csv)، [Excel الزامات](assets/Clause_Domains.xlsx) و [توضیحات نگاشت](docs/ANNEX-A-MAPPING.md) همراه بسته‌اند.

اقدامات اصلاحی دو زیرمنو دارد: پروژه‌های بهبود و داشبورد شکاف‌های بحرانی و اقدامات معوق. گسترهٔ پروژه‌ها میله‌ای است؛ کارت‌های رنگی A/B/C، بودجهٔ اختیاری و تخصیص‌های متعدد حفظ شده‌اند. داشبورد مستقل شکاف‌ها، شاخص‌ها و نمودارهای عملیاتی و فهرست قابل پیگیری دارد.

ساختار سه‌زیرمنویی RTP و BCMS، دو گرید RTP، شماتیک اختصاصی هر طرح BCMS، تاریخ شمسی، پشتیبان و گزارش‌ها حفظ شده‌اند. داده‌ها در مرورگر ذخیره می‌شوند؛ خود فایل HTML با ورود اطلاعات تغییر نمی‌کند. از بخش پشتیبانی مرتب پشتیبان JSON بگیرید.

راهنما و فرمول‌ها در `docs` قرار دارند. برای استفادهٔ روزانه اجرای کدهای Source لازم نیست. برای توسعه:

```sh
npm ci
npm run build
npm test
```

آزمون‌های مرورگر با Python، Playwright و Chromium در پوشهٔ `tests` قرار دارند.
