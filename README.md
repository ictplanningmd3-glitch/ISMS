# دیدبان امنیت ۱۲ — کاملاً آفلاین

[دانلود ZIP نسخهٔ ۱۲](Didban_Amniat_Offline_v12.zip?raw=true)

ZIP را استخراج و `Didban_Amniat_Offline.html` یا `START_HERE.html` را با Chrome یا Edge باز کنید. برنامه، فونت‌ها، نمودارها و خروجی‌های Word و Excel داخل بسته‌اند؛ اینترنت، نصب، سرور و CDN لازم نیست.

در نسخهٔ ۱۲، صفحهٔ اقدامات اصلاحی نمودار گسترهٔ پروژه‌ها در سرفصل‌های استاندارد و حوزه‌های مفهومی Annex A، نمودار آخرین وضعیت و پیشرفت، و تفکیک A/B/C دارد. A یک‌ماهه، B دوماهه و C سه‌ماهه است و کارت‌های هر گروه رنگ مستقل دارند. در تعریف پروژه می‌توان سرفصل، بند دقیق یا هر دو را انتخاب کرد. بودجهٔ جمع‌شوندهٔ هر اقدام شامل مصوب و تاریخ، تخصیص‌های تکرارشونده، جمع تخصیص و مانده است.

«نقطه قوت (Good Point)» با رنگ بنفش پررنگ به نتیجهٔ ممیزی، رادار، نمودارهای انطباق، جدول نهایی و گزارش‌ها افزوده شده است. وضعیت پیاده‌سازی از نتیجهٔ انطباق مستقل می‌ماند.

در داشبورد مدیریتی نمودار توازن پیاده‌سازی بزرگ‌تر شده، توزیع پیاده‌سازی به شکل پای کامل است و انطباق در دامنه‌ها با میله‌های جداگانه نمایش داده می‌شود. جدول انطباق زمینهٔ کم‌رنگ هر وضعیت و اعداد بولد دارد. بنر با همان لوگو و طرح پررنگ‌تر بازطراحی شده است.

رنگ‌های پیاده‌سازی در سراسر سایت: اجرا نشده قرمز، برنامه‌ریزی زرد، اجرای جزئی فیروزه‌ای، اجرا شده سبز، اثربخشی تأییدشده بنفش روشن و ارزیابی‌نشده خاکستری روشن. این مجموعه از رنگ‌های انطباق با استاندارد مستقل است.

نام ممیز هر بند و کنترل بالای «انطباق با استاندارد» قرار دارد. بخش جمع‌شوندهٔ «اطلاعات ممیزی قبلی» فقط اقدام اصلاحی و انطباق قبلی را می‌گیرد.

داشبورد BCMS فقط نمای کلی، موارد نیازمند بررسی و فهرست همهٔ طرح‌ها را دارد. با کلیک روی نام طرح، صفحهٔ همان طرح باز می‌شود؛ نمودار آن فقط در انتهای همان صفحه است. فرم‌ها برچسب فارسی و انگلیسی دارند و پرسش‌های وضعیت و آزمون BCP فقط پس از پاسخ «بله» به وجود طرح نمایش داده می‌شوند.

شماتیک جمع‌وجور و انگلیسی مطابق مرجع Business Continuity Recovery Timeline است: Last Consistent Backup، Disaster(T0)، RPO، RTO، MBCO، MTPD، KDS و مراحل بازگشت به100٪. مراحل هدف، قابلیت فعلی و آزمون جدا وارد می‌شوند؛ آخرین پشتیبان از حداکثر مجاز RPO مستقل است و مراحل ساختگی تولید نمی‌شوند.

سه زیرمنوی هر یک از ماژول‌های RTP و BCMS، دو گرید RTP، پنجرهٔ ثبت پروژه، تقویم شمسی، پشتیبان و گزارش‌ها حفظ شده‌اند. داده‌ها در مرورگر ذخیره می‌شوند؛ خود فایل HTML با ورود اطلاعات تغییر نمی‌کند. از بخش پشتیبانی مرتب پشتیبان JSON بگیرید. اطلاعات ماژول‌های مستقل وارد داشبورد اصلی ممیزی نمی‌شود.

راهنما و فرمول‌ها در `docs` قرار دارند. برای استفاده از برنامه اجرای کدهای Source لازم نیست. برای توسعه:

```sh
npm ci
npm run build
npm test
```

آزمون‌های مرورگر با Python، Playwright و Chromium در `tests/browser.py`، `tests/browser-v11.py` و `tests/browser-v12.py` قرار دارند.
