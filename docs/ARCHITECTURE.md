# معماری نسخهٔ ۸

خروجی یک HTML مستقل حاوی React، JSZip، فونت‌ها، قالب گزارش و تمام کدهاست. هیچ درخواست شبکه‌ای در زمان اجرا لازم نیست. فایل Fresh فضای جدا دارد.

ساخت با `build.py` از منبع نسخهٔ ۶ در `src/base-v6.html` انجام می‌شود. جایگزینی‌ها دارای کنترل anchor هستند. Babel فقط هنگام ساخت ورودی‌های تاریخ و نمایش تاریخِ React را تبدیل می‌کند؛ Babel و esbuild همراه برنامه اجرا نمی‌شوند.

ماژول‌های مینیمال دادهٔ پروژه‌محور و مستقل دارند: `didban-rtp-independent-v2` شامل projects/activities/payments و `didban-bcms-independent-v2` شامل assessments/settings. ساختارهای حجیم نسخهٔ ۷ و حساب‌ها/نقش‌ها/گردش کار ماژول‌های آن حذف شده‌اند. قرارداد داده نسخهٔ ۲ است و مهاجرت دادهٔ ماژول‌های نسخهٔ ۷ پشتیبانی نمی‌شود.

نوشتن معتبر، اتمیک و همراه شمارهٔ revision است. تعارض تغییر در پنجرهٔ دیگر رد می‌شود. دادهٔ خراب بازنویسی نمی‌شود. ذخیره در localStorage مرورگر انجام می‌شود؛ پیوست‌ها base64 هستند. JSON کامل پروژه شامل هر دو ماژول است. پشتیبان JSON راه انتقال بین مسیرها و مرورگرهاست.

نمایش و تقویم شمسی بر پایهٔ Intl با تبدیل معکوس و اعتبارسنجی روز کبیسه است. ذخیرهٔ فنی تاریخ ISO است تا مقایسهٔ تاریخ قابل اتکا بماند. زمان‌های BCMS به دقیقه‌اند.

جدول Excel از XLSX و TSV می‌خواند؛ رشته‌های مشترک، متن inline، درصد و تاریخ Excel پشتیبانی می‌شود. فایل‌های بزرگ و XML دارای DTD رد می‌شوند. فرمول اجرا نمی‌شود؛ مقدار cacheشده خوانده می‌شود. خروجی XLSX با سلول‌های متنی امن، RTL و سطر عنوان ثابت است.

محدودیت: دادهٔ مرورگر چندکاربره یا رمزگذاری‌شده نیست. تأیید مالک، تأیید ثبت‌شدهٔ محلی است. از داده‌ها مرتب پشتیبان بگیرید. منابع توسعهٔ داخل ZIP برای اجرای روزانه لازم نیستند.
